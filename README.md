# Vergi Hesaplayıcısı (Tax Calculator)

## Proje Hakkında
Bu proje, Nesne Tabanlı Programlama dersi kapsamında Python kullanılarak geliştirilmiş basit bir vergi hesaplama uygulamasıdır. Kullanıcının yıllık gelirine göre belirlenen vergi kuralları doğrultusunda ödemesi gereken vergi miktarını hesaplar.

## Proje Ne Yapar?
- Kullanıcıdan yıllık gelir bilgisini alır.
- `if-else` koşul ifadelerini kullanarak gelir düzeyine uygun vergiyi hesaplar.
- Hesaplanan vergi negatifse sonucu sıfıra eşitler.
- `round()` fonksiyonuyla sonucu tam talere yuvarlar.
- Vergi miktarını ekrana yazdırır.

## Proje Neden Faydalıdır?
Bu çalışma, Python'da koşullu ifadelerin, karşılaştırma operatörlerinin, matematiksel işlemlerin ve yuvarlama fonksiyonunun kullanımını öğrenmek amacıyla hazırlanmıştır.

## Proje Nasıl Çalıştırılır?
1. Python 3'ü bilgisayarınıza yükleyin.
2. Proje dosyasını Python IDLE veya başka bir Python editöründe açın.
3. Programı çalıştırın.
4. İstenilen yıllık gelir bilgisini girin.
5. Hesaplanan vergi miktarını görüntüleyin.

## Örnek Kullanım

**Girdi:**
```text
Enter the annual income: 10000
```

**Çıktı:**
```text
The tax is: 1244.0 thalers
```
